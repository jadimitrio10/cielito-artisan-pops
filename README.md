# Cielito Artisan Pops — Landing Page

A single-file, scroll-animated landing page for **Cielito Artisan Pops**, a premium
artisan popsicle brand based in Wynwood, Miami.

## What's inside
- `index.html` — the entire site (HTML + CSS + JS in one file)

## Tech
- Vanilla HTML/CSS/JS — no build step required
- [GSAP + ScrollTrigger](https://gsap.com/) for parallax & scroll timelines
- [Framer Motion](https://www.framer.com/motion/) for entrance/reveal animations
- [Lenis](https://lenis.darkroom.engineering/) for smooth scrolling
- Google Fonts (Playfair Display + DM Sans)
- Gallery images optimized on the fly via [wsrv.nl](https://wsrv.nl)

## Run locally
Just open `index.html` in a browser — that's it.
